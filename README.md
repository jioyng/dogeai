# DODGE

사방에서 날아오는 탄을 피하며 10개 스테이지와 보스를 돌파하는 HTML5 닷지 게임입니다.
설치 가능한 웹앱(PWA)이라 휴대폰과 PC에서 앱처럼 설치하고 오프라인으로 플레이할 수 있습니다.

## 플레이

- **온라인**: https://jioyng.github.io/dogeai/
- **휴대폰에 설치**: 위 주소를 Chrome(안드로이드)이나 Safari(아이폰)로 열고 "홈 화면에 추가" 또는 "앱 설치"
  - 휴대폰 **가로 화면 전용**입니다. 설치한 앱은 전체 화면 + 가로 고정으로 실행됩니다.
  - 화면 아무 곳이나 드래그하면 캐릭터가 손가락을 따라 움직이고, 왼쪽 아래 ⏸ 버튼으로 일시정지합니다.
- **PC에서 로컬 실행**: `start-game.bat` 더블클릭 → 브라우저에서 `http://localhost:8765` 열림

## 조작

| 동작 | 키 |
|---|---|
| 이동 | 방향키 / WASD / 마우스·터치 드래그 |
| 일시정지 | P 또는 Esc |
| 소리 켜기/끄기 | M |

보스전에서는 아이템을 먹어 보스를 공격합니다.

| 아이템 | 효과 |
|---|---|
| ★ 에너지 오브 | 보스 공격 1회 |
| ⚡ 트리플 샷 | 3연타 |
| 💣 폭탄 | 화면의 탄 모두 제거 + 2연타 |
| 🛡 방패 | 피격 1회 방어 |
| ⏳ 시간 감속 | 5초간 탄 속도 감소 |
| ❤ 생명 | 생명 +1 |

## 파일 구성

| 파일 | 내용 |
|---|---|
| `index.html`, `style.css` | 화면 |
| `game.js` | 게임 엔진 (탄 패턴, 보스, 아이템, 배경) |
| `stages.js` | 10개 스테이지 설정 (`waveTime`: 버티기 시간, `hp`: 보스 체력) |
| `audio.js` | 효과음과 배경음악 (Web Audio API로 합성) |
| `manifest.webmanifest`, `sw.js`, `pwa.js`, `icons/` | PWA 설치와 오프라인 실행 |
| `server.ps1`, `start-game.bat` | Windows용 로컬 서버 |
